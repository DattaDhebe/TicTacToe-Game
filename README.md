# Tic-Tac-Toe · Bash

A terminal game exercise using Bash arrays, board state, player symbols and row/column checks.

**BASH · TIC-TAC-TOE · LEARNING**

## What is included

The implementation is contained in [TicTacToe.sh](TicTacToe.sh). It demonstrates a three-by-three board, display functions, cell updates and checks for occupied positions.

## Getting started

Use Bash 4+ because the script uses associative arrays.

```bash
bash TicTacToe.sh
```

Use Linux, WSL or another Bash 4+ environment. Stop the script with Ctrl+C if needed.
